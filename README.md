# Python Cybersecurity Tools

A collection of Python tools built for cybersecurity and security-related purposes.

## 📂 Tools Included

### 1. Password Generator
A secure random password generator. Specify how many letters, numbers and symbols you want — the password is randomly shuffled every time.
- Concepts: random module, lists, loops, `random.shuffle()`
- Use case: Generating strong, unpredictable passwords
